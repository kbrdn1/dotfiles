# Guide Style Markdown

## Structure
- Un seul H1 par document (titre)
- Hiérarchie logique: H2 → H3 → H4
- Lignes vides avant/après headers
- Max 100 caractères par ligne

## Code
- Inline: `variable` pour noms courts
- Blocs: avec langage spécifié
- Exemples exécutables quand possible

## Liens
- Texte descriptif: `[Guide installation](./install.md)`
- Pas de "cliquez ici"
- Chemins relatifs préférés

## Tableaux
```markdown
| Colonne 1 | Colonne 2 |
|-----------|-----------|
| Valeur 1  | Valeur 2  |
```

## Conventions
- Listes: tirets `-` (pas `*`)
- Emphasis: `**gras**` pour important
- Code: backticks pour termes techniques
- Admonitions: `> **Note**: ...`
