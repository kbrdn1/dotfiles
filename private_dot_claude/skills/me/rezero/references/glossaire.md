# Glossaire vivant — terminologie Re:Zero FR

Fichier **vivant** : ajouter chaque nouveau terme rencontré (avec source), ne jamais modifier un
terme déjà utilisé dans un chapitre livré sans le signaler à l'utilisateur.

Statuts : `officiel` (édition/VF/wiki FR attesté) · `communautaire` (usage FR dominant, non
officiel) · `à vérifier` (choix provisoire — confirmer contre l'édition Ofelbe ou les sous-titres
officiels à la première occasion, puis promouvoir).

Établi le 2026-08-14 (sources : rezero.fandom.com/fr, rezerowebnovelfr.wordpress.com, Ofelbe).

## Règles d'usage transverses

- **Ordre des noms** : occidental — Subaru Natsuki, pas Natsuki Subaru. **Exception** : quand
  l'original emploie le nom complet en registre formel/emphatique (« Natsuki Subaru » dans la
  narration, ou entre guillemets pour désigner le personnage-façade), garder l'ordre japonais —
  c'est un procédé de Nagatsuki, pas une inattention. Précédent : les chapitres publiés.
- **Honorifiques** : conservés quand ils portent la voix du personnage (« Emilia-tan » de Subaru,
  « -sama » dans la bouche de Rem) ; noter le choix en note de traduction la première fois.
- **Accents FR attestés** : Émilia, Béatrice, Pételgeuse Romanée-Conti (fandom FR). Dans le corps
  du texte, suivre ces graphies.
- **Sorts et incantations** : conservés tels quels (Shamak, Minya, El Goa…) — pas de localisation
  FR attestée, et les traduire casserait la classification El/Ul/Al.

## Enrichissement de masse (2026-08-14)

Le glossaire du site (`~/Desktop/RE:Zero Stories/_site/glossary.js`) a été étoffé par deux
workflows multi-agents (26 agents sonnet x-high au total) : **+147 fiches** (186 au total) sur
7 catégories — personnages (arcs 1-8, Vollachia et Neuf Généraux Divins compris), lieux,
concepts, factions, événements, objets, races — chacune avec tag `arc` anti-spoiler, note FR
sans spoiler, liens wiki EN/FR vérifiés, et image quand l'API du wiki en fournit une.
Méthode reproductible : inventaire par catégories via l'API MediaWiki → fiches par lots de 12
(extracts `exintro` groupés) → passe de contrôle (drop/rename/rearc/renote) → merge par
`scratchpad/glossaire/merge_glossary.py` + images par `fetch_entity_images.py` (pageimages en
batch, crop 96px, régénération de portraits.css, injection `img:`). Le fichier maître de
terminologie reste CE fichier ; glossary.js porte les fiches encyclopédiques du volet.
