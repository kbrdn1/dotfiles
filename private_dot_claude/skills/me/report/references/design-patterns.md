# Motifs repris de « System Design » (designed-to-scale)

Source : designed-to-scale.vercel.app, conçu par @DilumSanjaya (captures partagées sur X, novembre 2026).
Captures locales, hors dépôt public : `~/Reports/_references/designed-to-scale/IMG_1979…1990.PNG`.
On reprend des **motifs d'usage**, pas le visuel : la charte reste kbrdn.dev v2.

| Motif (capture) | Ce qu'il fait bien | Où il vit dans me:report |
|---|---|---|
| Colonne de gauche : arbre du cours, compteurs `0/3`, bloc « Progress » en bas | navigation toujours visible sans voler de place au contenu | sommaire à gauche, compteurs par section, récap des réponses et des annotations dessous |
| Rangée de mesures en tête de scène, liseré vert ou rouge selon l'état | l'état se lit avant le texte | chiffres de l'en-tête liserés (CI rouge, bloquants, propre) |
| Frise « In this lesson » : pastilles numérotées reliées, étape courante pleine | avancer étape par étape, voir où on en est | review **passe par passe** ; questions pas à pas |
| Panneau d'étape : `STEP 7 / 13`, tag PROBLEM / SOLUTION / TECHNIQUE, Back / Next | une étape = un titre, un texte court, une décision | détail d'une passe de review ; formulaire de questions |
| Encadrés WATCH OUT (rouge), KEY IDEA (violet), GOOD TO KNOW (vert) | le point important sort du texte | `> [!WATCH]`, `> [!KEY]`, `> [!GOOD]` dans le markdown des notes |
| « What changed » avec `+` / `~` / `−` | ce qui bouge entre deux états, en trois lignes | changements entre deux passes ; ce qu'un refresh a modifié |
| « You'll learn » : liste à cocher | progression lisible d'un coup d'œil | récap des réponses (cochée = répondue) |
| Raccourcis en pied de panneau : `← → step · R replay · Space pause` | découvrables sans encombrer | bande de raccourcis en bas d'écran |
| Palette ⌘K : résultats groupés (lessons, concepts), `↑↓ move · ↵ open · esc close` | aller n'importe où au clavier | palette ⌘K : sections, fichiers, findings, sources, commits |
| Scène isométrique animée (nœuds, paquets, légende, Replay / Pause) | montre un mécanisme vivant, pas un schéma figé | pas repris : mermaid reste le format des diagrammes. Piste : un rendu isométrique pour les diagrammes d'architecture, si un rapport en a besoin |
