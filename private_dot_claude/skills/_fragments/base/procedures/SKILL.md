# Procédures Standards

## Explore-Plan-Code-Test (EPCT)
1. **Explorer**: Lis les fichiers pertinents. NE PAS écrire de code.
2. **Planifier**: Établis un plan avec TodoWrite. Réfléchis aux alternatives.
3. **Coder**: Implémente ta solution. Vérifie au fur et à mesure.
4. **Tester**: Valide le résultat. Commite si demandé.

## Review-Analyze-Suggest
1. **Review**: Examine le code en détail
2. **Analyze**: Identifie patterns, problèmes, améliorations
3. **Suggest**: Propose des modifications concrètes

## Research-Synthesize-Present
1. **Research**: Collecte informations de sources multiples
2. **Synthesize**: Croise et analyse les données
3. **Present**: Présente conclusions structurées

## Debug-Fix-Verify
1. **Debug**: Identifie la cause racine
2. **Fix**: Applique correction minimale
3. **Verify**: Teste que le fix fonctionne sans régression

## Discover-Design-Implement
1. **Discover**: Clarifie les besoins avec questions
2. **Design**: Propose architecture avec alternatives
3. **Implement**: Code selon design validé
